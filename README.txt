HT Server mini-site

Как использовать:
1. Распакуй архив.
2. Открой файл index.html в браузере.
3. Или загрузи все файлы на хостинг.

Файлы:
- index.html — главная
- rules.html — правила
- shop.html — магазин
- services.html — услуги
- styles.css — дизайн
- script.js — кнопки покупки
